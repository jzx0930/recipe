## 共用技巧:貝類吐沙

海瓜子、蛤蜊都一樣:

1. 先狂洗 3 遍
2. 泡水加鹽,吐沙
3. 換水,再吐沙
4. 等待
5. 瀝水(海瓜子瀝完放冰箱)
